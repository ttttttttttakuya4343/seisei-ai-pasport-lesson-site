# 第4章 生成AIを安全に使うために (シラバス/マンガテキスト書き起こし)

4章の学習範囲（page_058〜page_079 / 書籍p114〜p156）から抽出したトピックと重要語句のまとめです。

## 4-1 インターネットリテラシーって？
- **生成AIの活用にはインターネットリテラシーが不可欠**
- インターネットの基本：公開情報がすべて正しいわけではなく、生成AIもその情報を学習しているため、情報の正しさを判断する力が必要。
- **インターネットリテラシーの構成要素（4つ）**:
  1. **テクノロジーの理解**（「しくみ」を知る。例: httpsの鍵マークは暗号化、クラウドの概念）
  2. **情報リテラシー**（探す→比べる→確かめる→使ってみる。一次情報までさかのぼるクセ）
  3. **セキュリティとプライバシー**（長くて強いパスワード＋二段階認証。怪しいリンクは踏まない）
  4. **デジタル市民権**（ネットの向こうの相手を尊重。差別的言動を避ける、事実と意見を分ける）

## 4-2 インターネットの落とし穴
- **危険な罠**:
  1. **フィッシング詐欺**: 実在のサービスを名乗るメールやSNSから偽サイトへ誘導し、ID/パスワードを盗む。
  2. **悪意のあるQRコード**: 偽のQRコードを貼り付け、詐欺サイトへ誘導。
  3. **危険なフリーWi-Fi**: 暗号化が弱い、偽のSSIDなどで通信ののぞき見や乗っ取りのリスク。個人情報入力や決済はNG。
  4. **マルウェア（悪意のあるソフトウェア）感染**:
     - **ランサムウェア**（データを勝手に暗号化して身代金要求）
     - **スパイウェア**（閲覧履歴や入力情報を密かに送信）
     - **スケアウェア**（偽の警告で不安を煽る）
     - **トロイの木馬**（無害に見せかけて侵入し不正動作）
  5. **ソーシャルエンジニアリング（人を騙す攻撃）**: 人の心理の隙を突く手法。
     - **スピアフィッシング**（特定個人や組織を標的）
     - **ベイト攻撃**（魅力的な情報で興味を引きマルウェア感染等）
     - **ブラックメール**（秘密情報を握り金銭要求）
     - **プレテキスト**（偽のシナリオでターゲットを騙す）

## 4-3 個人情報を守ろう！
- **プライバシー設定**: SNS等で自分の情報の公開範囲（プロフ、写真、位置情報等）を自分自身でコントロールする。
- **個人情報保護法**:
  - **個人情報とは**：生存する個人に関する情報（氏名、生年月日、顔写真等）、および**個人識別符号**（マイナンバー、運転免許証番号、顔認証データ等）。
  - ※死者の情報や法人の情報は「個人情報」にあたらない。
- **より注意が必要な情報**:
  - **要配慮個人情報**: 人種、信条、病歴、犯罪歴など不利益を受けやすい情報。原則として事前の「本人の明確な同意」が必要。漏えい時は「個人情報保護委員会」へ報告。
  - **機微（センシティブ）情報**: （金融分野のガイドライン等）政治的見解、宗教、性生活等さらに厳格。原則として取得・利用・第三者提供が禁止。
- **匿名加工情報**: 個人を特定・復元できないように加工したデータ。第三者提供可能だが、匿名加工情報である旨の明示等のルールがある。
- **生成AIと個人情報**: 入力時、利用目的の範囲内か、AI提供事業者のプライバシーポリシー等で「入力内容が機械学習に使われるか」を確認する。

## 4-4 作品や画像の権利を知ろう！
- **AI生成物と著作権**:
  - AIが自律的に生成したものには原則として著作権は発生しない。
  - 人が「創作意図」を持ち、「創作的寄与（具体的な指示や修正）」を加えた場合は著作物となる可能性がある。
  - **著作権の基本**：無方式主義（登録不要、創作時に自動発生）。保護期間は原則として死後（法人は公表後）70年間。
- **その他の権利**:
  - **肖像権**: 自分の顔や姿を無断で撮影・公開・利用されない権利（憲法13条の幸福追求権に基づく）。
  - **パブリシティ権**: 著名人の氏名・画像等が持つ「顧客吸引力（経済的価値）」を無断利用されないように保護。
  - **特許権**: 新しい発明・技術・プロセスを保護。特許庁への出願・審査・登録が必要（原則20年）。
  - **商標権**: 商品やサービスを区別するマークやロゴ・ブランド名を保護（10年、更新可能）。
  - **意匠権**: 物品や画像の「デザイン（形状・模様・色彩）」を保護（最長25年）。

## 4-5 不正競争防止法
- 企業同士がフェアに競争できるようにするための法律。
- **主な不正競争**:
  1. 周知の商品等表示主体の混同行為（ある程度知られているものを真似て混同させる）
  2. 著名な商品等表示の冒用行為（全国的に知られているものを無関係な業者が名乗る、混同は不要）
  3. 商品形態の模倣行為
  4. **営業秘密に係る不正行為**。要件3つ：**秘密管理性**、**有用性**、**非公知性**。
  5. **限定提供データに係る不正行為**。要件3つ：**限定提供性**、**相当量蓄積性**、**電磁的管理性**。

## 4-6 人が主役！AI社会の理念とガイドライン
- **AI社会の基本理念（目指す社会像）**:
  ア）人間の尊厳が尊重され、イ）多様な幸せを追求でき、ウ）持続可能である社会。（＝人間中心）
- **AI事業者ガイドライン（第1.0版/1.1版）**: 2024年4月に経産省と総務省が公表。法的拘束力はないが、AIに関する基本的な考え方・行動基準を示す。
  - 構成はピラミッド構造（A: 基本理念、B: 原則、C: 共通の指針、D: 高度なAI向け、E:AIガバナンス）。
- **共通の指針（10項目）**:
  1. 人間中心
  2. 安全性
  3. 公平性（バイアスの回避）
  4. プライバシー保護
  5. セキュリティ確保
  6. 透明性
  7. アカウンタビリティ（説明責任、トレーサビリティの確保）
  8. 教育・リテラシー
  9. 公正競争確保
  10. イノベーション
- **AI事業活動を担う3つの主体**:
  1. **AI開発者**（AI Developer）：AIシステムを研究・構築。
  2. **AI提供者**（Provider）：AIシステム・サービスを利用者に提供し付加価値を加える。
  3. **AI利用者**（Business User）：提供されたAIを適正に利用し、出力を鵜呑みにせず人の確認を介在させる。

## 4-7 AI新法ってどんな法律？
- **日本初のAI新法（2025年6月4日公布）**: 正式名称「人工知能関連技術の研究開発及び活用の推進に関する法律」。
- イノベーションの促進とリスク対応の両立を目指して設計されており、厳しい罰則のある「規制法」ではなく、企業の自主性を尊重しAIの開発・活用を後押しする**「推進法」**です。（EUのAI規制法のような巨額の罰金は伴いません）

- **活用事業者の責務**: AIを事業で使う企業や、AIを使った製品・サービスを提供しようとする主体には、次のような主要な義務が課されます。
  1. 基本理念に則った積極的なAI活用
  2. 事業活動の効率化・高度化・新産業創出への努力
  3. 国や地方公共団体が実施する施策への「**協力義務（強制）**」
  ※ 協力義務についても、違反による直接的な**罰則（罰金など）はありません**。しかし、単なる「できれば協力してね」という努力義務ではなく、法律上のルールとして**「必ず協力しなければならない」**という正式な責任（義務）が課されている点に注意が必要です。

- **AI事業者ガイドラインとの関係**: 
  - AI事業者ガイドライン（第1.1版）は、あくまで法的拘束力のない任意の指針であり、「AIをどう運用するか」を示します。
  - AI新法は、「国の調査権限や悪質事業者への対応措置」といった、最低限の土台と国の関与を定めた法律です。
  - 両者は性質と役割分担が異なるため、**相互補完関係**（互いに補完し合う関係）にあります。AI新法が制定されたからといって、ガイドラインが失効したわけではありません。
