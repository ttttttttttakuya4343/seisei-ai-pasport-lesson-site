## 🎯 実装方法（4-0で実装済みのパターンを踏襲）

### 問題形式
PDFの確認問題は**○×形式**です。4択ではありません。

### HTMLテンプレート

```html
<!-- 確認問題セクション -->
<div class="section" id="quiz">
    <h2>✍️ 確認問題</h2>
    <p>以下の文章が正しい場合は〇、誤っている場合は×を選んでください。</p>

    <div class="quiz-question">
        <p><strong>問題XX:</strong> [問題文]</p>
        <ul class="quiz-options">
            <li onclick="selectAnswer(this, true/false, '[フィードバック]')">〇</li>
            <li onclick="selectAnswer(this, false/true, '[フィードバック]')">×</li>
        </ul>
        <div class="quiz-feedback" style="display: none;"></div>
    </div>

    <!-- 以下、問題を繰り返し -->
</div>
```

### フィードバックの書き方

**正解の場合:**
```javascript
onclick="selectAnswer(this, true, '✅ 正解！[question.txtの解答・解説をそのまま記載]')"
```

**不正解の場合:**
```javascript
onclick="selectAnswer(this, false, '❌ 不正解。[question.txtの解答・解説のエッセンスを簡潔に記載]')"
```

### 具体例（問題13の場合）

```html
<div class="quiz-question">
    <p><strong>問題13:</strong> プライバシー設定をせずにインターネットやアプリケーションを利用していると、知らぬ間にプライベートな情報が閲覧・収集される可能性がある。</p>
    <ul class="quiz-options">
        <li onclick="selectAnswer(this, true, '✅ 正解！プライバシー設定とは、他のユーザーや企業が自分の個人情報にどの程度アクセスできるのかを設定することです。プライバシー設定をせずにインターネットやアプリケーションを利用していると、知らぬ間にプライベートな情報が閲覧・収集される可能性があります。')">〇</li>
        <li onclick="selectAnswer(this, false, '❌ 不正解。プライバシー設定をしないと、プライベートな情報が閲覧・収集される可能性があります。')">×</li>
    </ul>
    <div class="quiz-feedback" style="display: none;"></div>
</div>
```

## 🔧 実装手順（推奨）

### Step 1: 既存のクイズセクションを特定
各ファイルで以下を検索：
- `<div class="section" id="quiz">` または
- `<!-- クイズセクション -->`

`<div class="lesson-navigation">` の直前行までがクイズセクション

### Step 3: 既存クイズを削除して新しい問題に置き換え
以下の方法で効率的に処理可能：

```bash
# ファイルをヘッダー部分（クイズの直前まで）とフッター部分（lesson-navigation以降）に分割
head -n [クイズ直前の行数] [ファイル名] > /tmp/header.html
# 新しいクイズセクションを追加（question.txtから○×形式で作成）
cat /tmp/quiz-section.html >> /tmp/header.html
# フッター部分を追加
tail -n +[lesson-navigation開始行] [ファイル名] >> /tmp/header.html
# 元ファイルを置き換え
mv /tmp/header.html [ファイル名]
```

### Step 4: lesson-metaの問題数を更新
各ファイルの `<div class="lesson-meta">` 内の問題数を更新：
```html
<span>📝 確認問題○問</span>
```

## ⚠️ 注意事項

1. **問題形式は○×のみ**: 4択ではありません。`〇` と `×` の2つの選択肢のみ。

2. **question.txtの問題番号とHTML内の問題番号を一致させる**:
   - 4-1a: 問題13-21 → HTML内でも「問題13」〜「問題21」と表記
   - 4-1b: 問題22-24 → HTML内でも「問題22」〜「問題24」と表記
   - 4-1c: 問題25-30 → HTML内でも「問題25」〜「問題30」と表記

3. **解答・解説はquestion.txtから正確にコピー**:
   - 正解のフィードバック: `✅ 正解！` + question.txtの【解答・解説】の内容
   - 不正解のフィードバック: `❌ 不正解。` + 簡潔な説明

4. **既存のJavaScript関数は変更不要**:
   - `selectAnswer()` 関数は既に各ファイルに実装済み
   - 新しいスクリプトの追加は不要

5. **HTMLの構造を維持**:
   - `<div class="section" id="quiz">` の構造を保つ
   - `<div class="quiz-question">` で各問題をラップ
   - `<div class="quiz-feedback" style="display: none;"></div>` を各問題の最後に配置
