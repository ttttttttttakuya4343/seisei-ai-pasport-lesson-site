第3章 セクション 3-1

生成AIのサービス

⏱️ 約15分 📝 クイズ5問

📝 テキスト生成AI

主要なテキスト生成サービス

ChatGPT

  • 開発： OpenAI
  • 特徴： 会話型AIのパイオニア、GPT-4oなど高度な推論が可能
  • 用途： 文章作成、翻訳、要約、プログラミング支援

Claude（クロード）

  • 開発： Anthropic
  • 特徴： 「憲法（Constitutional AI）」による高い安全性と長文処理能力

Gemini（ジェミニ）

  • 開発： Google
  • 特徴： テキスト、画像、音声を最初から理解できる「ネイティブマルチモーダル」

Copilot（コパイロット）

  • 提供： Microsoft
  • 特徴： WordやExcelなどのOfficeアプリケーションとの強力な連携

🎨 画像生成AI

主要な画像生成サービス

Midjourney（ミッドジャーニー）

  • プラットフォーム： Discord上で動作する画像生成AIサービス
  • 特徴： 芸術的で美しい画像生成に定評
  • 用途： イラスト、デザイン、コンセプトアート

Stable Diffusion（ステーブルディフュージョン）

  • 開発： Stability AI
  • 特徴： オープンソース（無償で公開されている）、自身のパソコン環境（ローカル）でも構築可能
  • 開発： Stability AI
  • 特徴： オープンソース、カスタマイズ可能
  • 技術： Diffusion Model（拡散モデル）

📖 用語解説：Diffusion Model（拡散モデル）

ノイズ（ランダムな点）から学習済みのパターンを使って徐々にノイズを除去し、画像を生成する技術。

DALL-E 3

  • 開発： OpenAI
  • 統合： ChatGPT Plus、Bing Image Creatorで利用可能
  • 特徴： 詳細なプロンプトから正確な画像生成

Adobe Firefly

  • 開発： Adobe
  • 特徴： 商用利用を前提とした安全な学習データ
  • 統合： Photoshop、Illustratorなどに統合

🎤 音声生成AI

主要な音声生成サービス

ElevenLabs

  • 特徴： 人間の声のイントネーションや感情表現をリアルに再現できる
  • 特徴： 29言語対応、感情表現も可能
  • 用途： オーディオブック、ナレーション、ゲーム
  • 音声クローニング： 自分の声を学習させることも可能

VOICEVOX

  • 開発： 日本のオープンソースプロジェクト
  • 特徴： 無料で商用利用可能
  • 用途： 動画のナレーション、読み上げソフト

Google Cloud Text-to-Speech

  • 提供： Google
  • 特徴： 220以上の音声、40以上の言語
  • 技術： WaveNet（ウェーブネット）

📖 用語解説：WaveNet

Googleが開発した、人間に近い自然な音声を生成する技術

🎬 動画生成AI

主要な動画生成サービス

Runway（ランウェイ）

  • Gen-2 / Gen-3 Alpha： テキストや画像からの高品質な動画生成
  • 機能： 動画の編集、背景の拡張・削除なども可能なオールインワンツール

Sora（ソラ）

  • 開発： OpenAI
  • 特徴： テキストから最長1分間の高解像度で物理法則に沿ったリアルな動画を生成

Veo3 / Lumiere

  • 開発： Google
  • 特徴： 商用レベルの高品質な動画生成機能を提供

HeyGen

  • 特徴： AIアバターによる動画生成
  • 用途： プレゼンテーション動画、教育コンテンツ
  • 機能： 多言語音声、リップシンク

📖 用語解説：リップシンク

映像内の人物の口の動きと、生成された音声を正確に同期させる技術。

🔍 画像認識AI

主要な画像認識サービス

Google Cloud Vision API

  • 機能： 物体検出、顔認識、企業ロゴ認識、テキスト抽出（OCR）
  • 用途： 画像分類、コンテンツモデレーション

Amazon Rekognition

  • 提供： Amazon Web Services (AWS)
  • 機能： 顔分析、有名人認識、不適切コンテンツ検出

Microsoft Computer Vision

  • 提供： Microsoft Azure
  • 機能： 画像説明文の自動生成、画像内のテキスト読み取り

📖 用語解説：OCR（Optical Character Recognition：光学文字認識）

画像内の文字を認識してテキストデータに変換する技術。近年はAIと組み合わせて精度が飛躍的に向上しています。
