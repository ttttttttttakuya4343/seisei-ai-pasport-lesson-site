その他の主要生成AI

⏱️ 約15分 📝 確認問題5問

🌍 1. そのほかの主な生成AI

生成AIはChatGPT以外にも、Googleの「Gemini」、Anthropicの「Claude」、Microsoftの「Copilot」など、異なる強みを持つものがあります。

🌐 2. Gemini（ジェミニ）

Geminiは、Google DeepMind社が開発するAIです。2023年末に初代のものが発表されて以来、1.5→2.0→2.5と進化版が公表されています。

テキストだけでなく、画像・音声・動画・PDFまで一度に理解できる「マルチモーダル設計」が最大の特徴です。また、問題の難しさに応じて「どれ程度考えるか」を自動調整できる機能（reasoning機構）も有しています。

Gemini 2.5 の派生モデル

最新のGemini 2.5では、次のような派生モデルがあります。

モデル名 特徴
Pro コード・数学・データ解析に強い最上位版（超長文も処理可）
Flash 応答が速くて安い。リアルタイム処理向き
Nano スマートフォンで使える軽量版

🛡️ 3. Claude（クロード）

ClaudeはAnthropic社が開発したAIで、独自の「Constitutional AI」というしくみにより、「有害でない・役に立つ・正直」というルールが組み込まれています。

Claudeのモデルラインナップ

Claudeには、次の3つのモデルがあります。

モデル名 特徴
Haiku 超速でコストも安い
Sonnet スピードと能力のバランス型
Opus 一番頭が良い推論型

Claude 4 の特徴

2025年に公開されたClaude 4では、外部ツールを呼び出しながら長時間の作業を進められるようになり、エージェント的な使い方が強化されています。

💼 4. Copilot（コパイロット）

Copilotは、Microsoft社が展開するAI群をまとめたブランドです。WordやExcel、Outlook、TeamsといったOfficeアプリに組み込まれており、資料作成やメール作成などの作業を手助けしてくれます。

ベースになっているのはOpenAIのGPT-4で、次のような種類のものがあります。

Copilotの種類

種類 特徴
Copilot Studio 自分の会社用にカスタムCopilotを作れる。
Copilot+ PC 「Recall」でPCの作業履歴をオフライン検索できる。
GitHub Copilot プログラマー向け。コード作成を補助。
Security Copilot セキュリティ対策を自動で支援。

📝 まとめ

  • Gemini（Google）： テキスト・画像・音声等を一度に理解するマルチモーダル設計。Pro・Flash・Nano等の派生モデルがある。
  • Claude（Anthropic）： Constitutional AI（Helpful・Harmless・Honest）に則った安全設計。Haiku・Sonnet・Opusなどのモデルがあり、エージェント利用も強化されている。
  • Copilot（Microsoft）： OpenAIのGPT-4をベースに各種Officeアプリに統合。「Recall」や用途別Copilotも展開。
